# 📊 Automatic Attendance Tracker & Payroll Management System | Excel

An Excel-based **Attendance Tracker & Payroll Management System** designed to automate employee attendance monitoring and salary calculations.

## 📌 Project Overview

This project simplifies manual attendance and payroll processes by connecting attendance data with salary calculations. It automatically calculates salary based on attendance, overtime, allowances, and deductions, also generating automated salary slips.

## 🎯 Project Objective

The main objective of this project was to demonstrate how **Excel can be used to automate repetitive HR and payroll tasks**, reduce manual calculations, and organize employee attendance and salary information in a structured system.


## 🔧 Key Features

- Employee attendance tracking
- Attendance based salary calculation
- Overtime calculation
- Allowances and deductions
- Automated salary slips
- Data Validation for accurate and consistent data entry
- Conditional Formatting for attendance status and important information
- Automated calculations using Excel formulas

## 🧮 Excel Functions Used

- `DATEVALUE`
- `TEXT`
- `COUNTIF`
- `EOMONTH`
- `VLOOKUP`
- `IFERROR`
- `SUM`
